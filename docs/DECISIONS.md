# Decision log

## 2026-09-24: execution model

All phases run sequentially in one VM and one working tree. No child sessions,
independent workers, or external compute are used.

## 2026-09-24: scientific interpretation

The optimization moves a conserved quantity of heat between explicitly
specified source and sink control volumes. It does not claim net planetary
cooling. Radiative escape, if evaluated, is a separate exploratory module.

## 2026-09-24: empirical endpoint

The human endpoint is thermal-stress exposure burden, not mortality. No
globally transferable epidemiological mortality function will be assumed
without direct evidence.
